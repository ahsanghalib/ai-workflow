# Review an Implementation PLAN

Use `plan-review` for one exact PLAN and its referenced SPEC.

Check approval status, task ordering, scope, architecture, contracts, schema
and migration safety, TDD evidence, environments, rollback, validation, and
security boundaries. Report actionable findings without editing the PLAN or
marking it approved.
