# Update Session State

Use `session-state` after meaningful work or before handoff.

Record the active PLAN, status, completed and in-progress work, blockers,
decisions, findings, validation, untested paths, and next exact action in
`SESSION_STATE.md`. Preserve the existing structure and keep it ignored by
Git. Do not store secrets, raw logs, or a transcript.

When project memory is enabled and the work is meaningful, also use
`agent-memory` to create one concise, reviewed episode.
