# Visual system and accessibility

Use this reference for readable, traceable pages. Visual polish cannot override
claim accuracy, supplied brand rules, or accessible communication.

## Readability

- Check the selected page at its intended mobile viewing size, not only zoomed
  in on a desktop canvas.
- Keep one dominant message per page and enough whitespace around it.
- Prefer fewer words at a readable size over dense copy or tiny footnotes.
- Check line breaks, punctuation, code, numbers, and URLs after rendering.
- Keep all pages at the same geometry unless an explicit exception is approved.

## Contrast and non-color cues

- Use sufficient contrast for text, icons, lines, and interactive-looking
  elements against their actual background.
- Do not communicate status, order, or category through color alone; add text,
  labels, patterns, position, or shape.
- Check muted text and footer/source text separately from headline text.
- Preserve meaning in grayscale and for common color-vision differences.

## Images, diagrams, and code

- Use only supplied or approved assets, with provenance and usage constraints.
- Describe what a diagram proves and what it does not prove.
- Do not use a decorative chart, screenshot, or generated image as evidence for
  a claim it cannot establish.
- Keep code fragments short, labeled, and readable; never expose secrets or
  private identifiers.
- Provide an alt/description note for meaningful imagery and diagrams, even if
  the final LinkedIn document cannot expose all accessibility metadata.

## Sources and disclosures

Place citations, attribution, sponsorship, affiliation, limitations, and legal
notices where the user approved them. Ensure source links remain traceable and
secure. A citation does not turn an unsupported interpretation into a fact.

## Final human review

When rendered page inspection is available, review every page at normal size
for hierarchy, clipping, overlap, overflow, contrast, legibility, source
placement, and visual consistency. Record which review occurred. If it was not
available, mark the corresponding QA item unverified.
