# Alternate carousel design systems

These are three complete, six-page portrait design options for review before a
direction is selected for a canonical PPTX build. Each option contains:

- `slides/` — rendered 1080 × 1350 PNG references, one per page;
- `carousel.pdf` — the matching six-page review export;
- `carousel-editable.svg` — the editable multi-page Inkscape source;
- `carousel-source.svg` and `pages/` — source and per-page SVG references.

Choose one option for a carousel and keep its page language consistent. Do not
mix layouts, chrome, or motifs across options. These are visual references and
editable exploration sources; the final LinkedIn deliverable remains a native
editable PPTX plus its matching PDF.

The skill chooses in this order: an explicit user direction, a content-fit
match, or the baseline system when the post is ambiguous. It uses random
selection only when the user explicitly asks for a random or surprise direction.

## Options

- `evidence-ledger` — light editorial ledger with evidence rows and structured
  retrieval notes. PNG references: `evidence-ledger/slides/`.
- `dark-signal` — dark editorial system built around traces, failure paths, and
  observability. PNG references: `dark-signal/slides/`.
- `modular-index` — light asymmetric grid with index rails, modular cards, and
  data bars. PNG references: `modular-index/slides/`.

All three use the approved Ahsan token palette and typography. Read the
selected option's PNG pages before authoring; preserve its composition and
spacing while rebuilding the final content as native editable presentation
objects.
