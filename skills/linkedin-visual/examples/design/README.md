# Canonical design references

These files are visual targets for the Ahsan LinkedIn visual system. They are
**references, not slide backgrounds**.

Canonical portrait templates are in `carousel-slides/slides/`.
Canonical square references are in `carousel-slides/standalone/`.
Alternate six-page design systems are indexed in
`carousel-options/README.md`: `evidence-ledger`, `dark-signal`, and
`modular-index`.

When generating a matching design, inspect the exact PNG corresponding to the
selected template and follow `../../references/visual-fidelity.md`.

`reference-board/` contains overview or duplicate images for human review only.
Do not treat them as individual template references.

When an alternate option is selected, inspect only that option's `slides/`
references and keep its composition consistent across the carousel. The SVG
and PDF files are included for source review and export comparison; do not use
them as flattened slide backgrounds in the final PPTX.
