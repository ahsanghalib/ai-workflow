# LinkedIn engagement topics

Use this default list only when the user does not provide a replacement. Search
terms broaden a topic; they do not create additional topics. Prioritize posts
where the discussion intersects with a real implementation, product, cost,
reliability, workflow, data, security, or business problem.

1. **AI integration and custom models**
   - Search terms: AI integration, custom models, model adaptation, fine-tuning,
     structured outputs, model evaluation, model routing, small language models,
     AI implementation, inference cost, production AI.
   - Commercial signal: teams deciding how to add AI to an existing product or
     reduce cost/reliability problems.

2. **Agentic systems and MCP**
   - Search terms: agentic systems, AI agents, tool use, agent workflows, Model
     Context Protocol, MCP servers, MCP clients, human-in-the-loop agents,
     authorization, agent reliability.
   - Commercial signal: teams moving from demos to controlled production workflows.

3. **RAG and context engineering**
   - Search terms: RAG, context engineering, retrieval quality, chunking,
     reranking, citations, grounding, context windows, retrieval evaluation.
   - Commercial signal: teams struggling with search quality, grounding,
     evaluation, latency, or cost.

4. **AI-engineering tooling and harnesses**
   - Search terms: AI engineering tools, coding agents, agent harnesses,
     evaluations, observability, prompt tooling, workflow automation, developer
     tooling, regression evaluation.
   - Commercial signal: engineering teams trying to make AI workflows repeatable,
     testable, or observable.

5. **Full-stack TypeScript, Node.js, and Python**
   - Search terms: full-stack TypeScript, Node.js, Python, backend engineering,
     frontend engineering, APIs, web applications, AI application development.
   - Commercial signal: product/engineering discussions where integration,
     architecture, or implementation help could plausibly be relevant.
